# Coding Instructions — Global

This repository is the **canonical, publicly readable source of coding
instructions** for AI agents and collaborators working on any project, in
any repository, under any account. It is intentionally project-agnostic:
these rules are not tied to a particular codebase, owner, or team.

Projects adopt these rules by referencing this repository from their own
`AGENTS.md` (see "How projects adopt these rules" below).

## How to apply these rules

These instructions apply to **any coding task where they are relevant**.

Not every project is broad or large enough for every check. Agents and
contributors must **judge applicability per repository**: scale the depth of
review, testing, and process to the size, risk, and maturity of the codebase.
When a rule cannot apply, note why rather than skipping it silently.

The authoritative instructions are maintained by the repository owner and
may evolve. Always read this file fresh at the start of work rather than
relying on a cached copy.

## Instructions

*The owner will publish the full coding instructions here.*

## How projects adopt these rules

1. Add an `AGENTS.md` at the root of the project repository.
2. In that file, include a short note plus a link to this repository, e.g.:

   > Coding instructions live in the canonical public repo (this one).
   > Read its `AGENTS.md` before making changes. Apply rules with judgement
   > appropriate to this repository's size and risk.

3. Agents working in the repo must fetch and follow the canonical file.
